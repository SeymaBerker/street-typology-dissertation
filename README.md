Seyma Berker | MSc Urban Spatial Science | UCL CASA 2026  
In partnership with Foster + Partners

## Notebooks

- `notebooks/01_data_collection.ipynb` — prepares OpenStreetMap-derived contextual data for the four study cities
- `notebooks/02_analysis_final.ipynb` — final dissertation analysis pipeline, including street typology classification and cross-city similarity search

## Cities

London (City of London), Barcelona (Eixample), Singapore (Central), Tokyo (Shinjuku)

## How to run

1. Run `01_data_collection.ipynb` to prepare the required contextual data
2. Run `02_analysis_final.ipynb` for the full dissertation analysis

## Requirements

`jreades/sds:2025-amd` Docker container
